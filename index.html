The ten exercises

  1. Clean the issue log: project names, category spelling, blank owners.
  2. Pass rate by program and stage against the exit target.
  3. Open issues by severity, and how many real root causes sit behind the Critical ones.
  4. Find the test station that fails too often, and when.
  5. Compare memory test failures by DIMM lot.
  6. Join thermal data to test runs and compare BMC firmware versions.
  7. LYRA-4U GPU temperature by ambient: firmware or design?
  8. Days to close by root cause, and open issues older than 30 days.
  9. Schedule slip for each gate, linked to its cause.
  10. Write the weekly status in Chinese: 紅燈 / 黃燈 / 綠燈, problem, owner, next step with a date.
